Wanderlust is a full-stack web application that allows users to explore, create, edit and review travel property listings.

Features

- User registration and login
- User authentication and authorization
- Create new property listings
- Edit and delete listings
- View property details
- Add reviews and ratings
- Image upload and cloud storage
- Responsive user interface
- Server-side validation
- Error handling and middleware

Technologies Used

### Frontend
- HTML
- CSS
- JavaScript
- Bootstrap
- EJS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Authentication
- Passport.js
- Express Session

### Cloud Services
- Cloudinary
